## Current Project Shape

Main components:

- `wikillm/core/`: shared types, registry, config loading, SQLite queue, LLM gateway client, and vault helpers.
- `wikillm/inputs/`: URL, YouTube, GitHub, PDF, and text adapters.
- `wikillm/knowledge/`: LLM distillation, Markdown vault writing, Milvus indexing, entity indexing, and log writing.
- `wikillm/outputs/`: CLI retrieval and Telegram bot.
- `wikillm/scanners/`: local source, feed, email, index, todos, review, and canonicalization utilities.
- `systemd/`: service installation and runtime units.

Runtime/deployment notes:

- Runtime config is local `config.toml` and should not be committed.
- Local state lives in `data/`, `notes/`, `sources/`, and `todos/`.
- Milvus Lite should not be shared by multiple writer processes; the Telegram bot is designed to drain the queue and own indexing.
