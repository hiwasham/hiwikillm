# Getting Started With wikillm

You'll set up `wikillm`, confirm its plugins load, capture one source, and ask a question over the indexed note.

## What You'll Need

- Python 3.11 or newer.
- The dependencies from `requirements.txt`.
- A `config.toml` copied from `config.example.toml`.
- A working OpenAI-compatible gateway token in the JSON file named by `[gateway].openclaw_config`.

This tutorial uses `https://example.com/` because it is stable and small.

## Step 1: Install Dependencies

From the project root:

```bash
python3 -m pip install --user -r requirements.txt
```

On Debian or Ubuntu systems that enforce PEP 668, use a virtual environment if possible. The project notes mention `--break-system-packages` only as a last resort for constrained Raspberry Pi setups.

## Step 2: Create Local Config

Copy the template:

```bash
cp config.example.toml config.toml
```

Edit these values:

```toml
[gateway]
openclaw_config = "/home/YOU/.openclaw/openclaw.json"
token_path = "models.providers.freemodel.apiKey"

[telegram]
bot_token = "REPLACE_WITH_YOUR_TELEGRAM_BOT_TOKEN"
owner_ids = []
```

`config.toml` is gitignored. Keep it private.

## Step 3: Check Plugin Registration

Run:

```bash
python3 -m wikillm list-plugins
```

Expected shape:

```text
inputs:
  - github
  - pdf
  - text
  - url
  - youtube
knowledge stages (in order):
  - llm-distill
  - markdown-vault
  - milvus-index
  - entity-index
  - log-writer
outputs:
  - cli-query
  - telegram-bot
```

You now know the package imports correctly and all active plugins are registered.

## Step 4: Capture One Source

Run one immediate distillation:

```bash
python3 -m wikillm distill https://example.com/
```

Expected result:

```text
/root/projects/hiwikillm/notes/YYYY/MM/<slug>.md
```

This command fetches the page, asks the distillation model to write a Markdown note, stores it under `notes/`, indexes chunks in Milvus, extracts entities, and appends to `notes/log.md`.

## Step 5: Ask A Question

Run pointer mode first because it does not make another LLM call:

```bash
python3 -m wikillm ask "What is this source about?" --mode pointer
```

You should see ranked note snippets with paths.

Then run synthesis mode:

```bash
python3 -m wikillm ask "What is this source about?"
```

Synthesis mode retrieves note chunks, sends them to the synthesis model, and prints an answer with source markers.

## Step 6: Generate Vault Indexes

Build the human-facing vault pages:

```bash
python3 -m wikillm build-index
python3 -m wikillm build-todos
```

Expected files:

```text
notes/index.md
todos/index.md
```

`notes/index.md` is the vault entry point. `todos/index.md` collects open questions generated by the LLM curator.

## What You Built

You now have a working local wiki-LLM loop:

```text
source URL -> Markdown note -> Milvus chunks -> cited Q&A
```

## Troubleshooting

### `FileNotFoundError: config.toml`

Copy `config.example.toml` to `config.toml` and fill in the local values.

### Gateway authentication fails

Check `[gateway].openclaw_config` and `token_path`. `token_path` is a dotted path inside the JSON file.

### No search results

Run:

```bash
python3 -m wikillm backfill
```

This re-indexes existing notes into Milvus.

### Milvus lock errors

Stop other processes that may be using `data/milvus.db`. Do not run multiple bot or indexing processes against the same Milvus Lite database.
