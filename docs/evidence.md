# Evidence Guide

Use this page to inspect the recovery artifacts:

- `PROJECT_RECOVERY.md`: human-readable recovery report
- `project-recovery-evidence.json`: machine-readable source ranking and scan evidence
- `project-recovery-transcripts.html`: full chat-style recovered transcript, with user messages highlighted
- `COMMIT_PLAN.md`: exact commit grouping recommendation

The transcript may be large. Start with the source-quality ranking in the recovery report.
